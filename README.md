# ObesityHealthCare
An Android application designed to help users manage and understand obesity by providing personalized health insights, AI-powered analysis, and multilingual support. This project serves as a comprehensive tool for health awareness, drawing on WHO guidelines to offer actionable advice.
# 🚀 About This Project
The Obesity Health Care app is a user-centric mobile tool built to empower individuals on their health journey. It allows users to calculate their Body Mass Index (BMI), receive personalized diet and exercise plans, and even analyze health reports using cutting-edge AI. With a focus on accessibility, the entire app is internationalized and includes a foundation for a voice-controlled AI assistant.
# ✨ Features
•🌍 Multilingual Support: Fully internationalized interface supporting English, Spanish, Hindi, and Bengali. The architecture is designed for easy expansion to other languages.
•👤 User Authentication Flow: A complete and user-friendly authentication journey:◦Language Selection: A dedicated screen for users to choose their preferred language upon first launch.◦Login & Registration: Secure-feeling screens for user login and a comprehensive registration form with interactive elements like a dropdown for gender and a pop-up calendar for date of birth.
•⚖️ BMI Calculator: An intuitive screen for users to calculate their BMI using weight (in kg) and height (in ft).
•🏠 AI-Powered Home Screen: A dynamic home screen that provides:◦A clear display of the user's calculated BMI.◦A detailed Diet Plan, Exercise Plan, and Daily Activity Suggestions generated by a simulated Gemini AI trained on WHO guidelines.
•🤖 AI Report Scanner: A powerful feature to help users understand their health reports:◦Camera & Gallery Integration: Users can either take a new photo of a report or select an existing image from their gallery.◦On-Device AI (ML Kit): Uses Google's ML Kit for fast and offline Optical Character Recognition (OCR) to extract text from the image.◦Gemini AI Analysis: The extracted text is sent to a simulated Gemini AI service, which provides a detailed analysis and action plan based on WHO data.
•🎤 Vocal AI Assistant (Foundation):◦Includes a microphone icon on the BMI screen to activate a voice assistant.◦Features a complete permission and speech-to-text flow to capture user questions.◦Includes a text-to-speech engine to speak responses back to the user.
•💳 Subscription Model (Foundation):◦The project includes the Google Play Billing Library.◦A dedicated placeholder screen is built to showcase subscription tiers, ready for implementation.

# 🛠️ Tech Stack & Architecture
•Language: 100% Kotlin
•UI: Jetpack Compose for a modern, declarative, and reactive user interface.
•Architecture: Single-Activity Architecture, following modern Android best practices.
•Navigation: Jetpack Navigation Compose for all screen transitions.
•Artificial Intelligence:◦Google ML Kit Text Recognition: For on-device, offline text scanning.◦Google AI (Gemini) SDK: For advanced AI-driven analysis and content generation.
•Billing: Google Play Billing Library for subscription services.
•Permissions & Media: Robust handling of Camera and Audio permissions, using a secure FileProvider for media handling.

•Enhance the Vocal AI Assistant: Expand the speech-to-text and text-to-speech capabilities to allow for full, conversational interactions with the Gemini model.
